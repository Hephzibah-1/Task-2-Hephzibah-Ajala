# DecodeLabs Project 2: Exploratory Data Analysis (EDA)

## Project Overview
This project focused on Exploratory Data Analysis (EDA) using Microsoft Excel to identify patterns, trends, distributions, and potential outliers in a dataset containing 1,200 records and 14 columns.

## Tools Used
- Microsoft Excel
- Excel Tables and formulas
- PivotTables
- Data visualization charts

## Key Tasks Performed
- **Data Cleaning and Validation:** Handled missing values, checked for duplicates, validated data types, and verified order-value calculations.
- **Descriptive Statistics:** Used `COUNT()`, `AVERAGE()`, `MEDIAN()`, `MIN()`, `MAX()`, and `STDEV.S()` to summarize the data.
- **Outlier Detection:** Used `QUARTILE.INC()` and the Interquartile Range (IQR) method to identify eight potential high-value outliers.
- **Correlation Analysis:** Applied `CORREL()` to examine relationships between quantity, unit price, and total price.
- **Trend Analysis:** Used PivotTables and charts to explore monthly changes in order values.
- **Insights and Recommendations:** Summarized key findings and proposed areas for further investigation.

## Key Findings
- The order-value distribution was right-skewed, with the mean higher than the median.
- Eight potential high-value outliers were identified. Their calculations were verified, so they were retained rather than automatically treated as errors.
- Unit price had a stronger positive correlation with total price than quantity did.
- Monthly order values fluctuated, with June 2024 recording the highest monthly total in the analyzed period.
- Order statuses varied across the dataset, highlighting areas for further investigation.

## Project Files
The Excel workbook contains:
- `Raw` — original dataset
- `Cleaned` — cleaned and validated dataset
- `Cleaning Log` — documented cleaning and validation activities
- `EDA Summary` — descriptive statistics, outlier analysis, findings, and recommendations
- `Time Analysis` — monthly order-value analysis and trend visualization

## Skills Demonstrated
Data cleaning, data validation, descriptive statistics, outlier detection, correlation analysis, trend analysis, data visualization, and analytical thinking.

This project strengthened my ability to use Excel to move beyond data preparation and investigate what the data reveals. It also reinforced the importance of validating unusual values before deciding whether they should be removed.
